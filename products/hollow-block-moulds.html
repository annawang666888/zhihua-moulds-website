Moulds for Concrete Hollow Blocks and Hollow Bricks

Hollow block moulds — also called concrete block making moulds or hollow bricks moulds — are used to cast the cored masonry units that form walls, partitions, boundary walls and ventilated screens. Because the core geometry decides both block weight and mortar key, hole shape and wall thickness are the two parameters buyers check first.

Zhihua supplies 54 hollow block mould designs: ABS three-in-one and two-in-one multi-cavity moulds that cast three blocks per pour, a 22-design double-sided S30 series in 30×30×10cm, numbered 20×20cm patterns, plus square-hole, round-hole, angled-hole, arched-hole and ventilation block moulds. Standard catalogue designs and OEM patterns are both available.

Hollow Block Mould Buyer Guide

Hollow block mould selection is driven by finished block size, hole geometry and how many blocks you need per pour. Multi-cavity ABS moulds cut labour per block but need a flatter casting bed.

Typical hollow block mould types

  • ABS three-in-one multi-cavity: casts three 20×20×10cm blocks per pour with double-smooth faces — the fastest option for volume production.
  • Double-sided S30 series: 22 pattern designs in 30×30×10cm, finished on both faces so blocks can be laid either way round.
  • Numbered 20×20cm designs: No.20-14 to No.20-28 plus No.104/105/106/109 — established patterns with proven demoulding.
  • Square, round & angled hole: core geometry chosen for block weight, mortar key and whether rebar passes through.

Project drawing checklist

For hollow block moulds, the key parameters are finished block dimensions, hole shape and wall thickness between cores. Tell us your target blocks-per-day and we can advise on cavity count.

  • Confirm finished block length × width × height (e.g. 20×20×10cm).
  • State hole shape, hole count and minimum wall thickness between cores.
  • Tell us target output per day so we can recommend single or multi-cavity moulds.

Hollow Block Mould FAQ

What is a hollow block mould used for?

A hollow block mould casts concrete masonry units with internal cores. The cores reduce block weight, save concrete, improve insulation and give mortar a mechanical key. Blocks are used for boundary walls, partitions and ventilated screens.

How many blocks can one mould cast per pour?

Single-cavity moulds cast one block per pour. Our ABS three-in-one moulds cast three blocks per pour and two-in-one moulds cast two, which significantly reduces labour cost per block.

What is the difference between a hollow block and a solid block mould?

A hollow block mould has core formers that create internal voids, so the finished unit is lighter and uses less concrete. A solid block mould produces a fully filled unit with higher compressive strength but more weight and material cost.

Can you make a custom hollow block mould from my drawing?

Yes. Send the block drawing or a sample photo with finished dimensions, hole layout and wall thickness. We review draft angles and demoulding direction, then quote OEM mould production.
