Moulds for Street Tree Pits, Planters and Landscape Edging

Tree ring and garden edging moulds are used to cast the concrete units that surround street trees, define planting beds and separate lawn from paving. On municipal streetscape projects, modular tree ring sets let one mould kit serve several tree pit diameters.

Zhihua supplies moulds for modular and multi-piece tree ring sets, decorative round rings including sunburst, cast-iron-look and cloud motifs, straight, elbow and corner segments, plus planter and garden edging stones. Sizes run from 40×27×6cm units up to 150×12.5×20cm segments.

Tree Ring Mould Buyer Guide

Tree ring mould selection starts from the finished tree pit diameter, then works back to whether a one-piece ring, a modular set or straight-and-corner segments is most economical.

Typical tree ring mould types

  • Modular multi-piece sets: four-piece and eight-piece kits that combine into different pit diameters from one mould family.
  • Decorative round rings: sunburst, cast-iron-look, cloud and petal motifs in 50×50 to 64.5×64.5cm formats.
  • Straight, elbow & corner segments: 40–150cm segments for square, rectangular and free-form pit surrounds.
  • Planter & garden edging stones: 40×27×6cm and 73×9×14cm units for planting bed and lawn borders.

Project drawing checklist

For tree ring moulds, the finished tree pit opening and the surround width drive everything else. Tell us the pit size and we can advise which segment combination is cheapest.

  • State the finished tree pit opening (inner diameter or clear square).
  • Confirm surround width, height and whether a corner piece is needed.
  • Say whether the ring is flush with paving or raised as a kerb.

Tree Ring Mould FAQ

What is a concrete tree ring used for?

Concrete tree rings surround street and park trees to protect the root zone, keep soil in place, stop pedestrians compacting the pit and give the streetscape a finished edge. They are also called tree grates or tree pit surrounds.

How do modular tree ring sets work?

A modular set uses repeated straight units plus corner units. By changing how many straight units are used per side, one mould kit can build several tree pit sizes, which lowers mould cost on multi-size projects.

Can you supply moulds for a specific tree pit diameter?

Yes. Tell us the finished pit opening and surround width. We can recommend a catalogue combination or quote an OEM mould for the exact profile.
