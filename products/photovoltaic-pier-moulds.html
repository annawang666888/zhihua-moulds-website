Photovoltaic Pier Moulds FAQ

Can you make photovoltaic pier moulds from project drawings?

Yes. Send the solar support base drawing, finished concrete dimensions and installation details. We can review mould structure and quotation.

Do you support grooved or plain solar base moulds?

Yes. We supply both grooved flat pier moulds and plain flat pier moulds, and can customize groove size, wall thickness and overall dimensions.

Can the pier mould size be customized?

Yes. Length, width, height, groove detail and wall thickness can be adjusted to match project drawings or sample photos.

Photovoltaic Pier Concrete Mould Buyer Guide

Photovoltaic pier moulds are usually quoted by finished concrete size and groove detail, because each solar farm or distributed PV project uses its own base schedule.

Typical photovoltaic pier types

  • Grooved flat pier: a flat rectangular base with a groove for support seat or cable routing.
  • Plain flat pier: a simple flat block used as a support base where no groove is needed.
  • Custom foundation block: project-specific size, embedded parts or lifting holes from drawings.

How to prepare a project enquiry

Instead of asking for a generic price list, send a component schedule so we can match catalogue sizes or quote custom moulds.

  • Send drawings, sample photos and quantity for each pier size.
  • Mark groove size, support seat detail, lifting holes or embedded parts.
  • Group components by site package to simplify mixed-SKU packing.
